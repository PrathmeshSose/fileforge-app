Our Core Promise ▼

FileForge – All Doc Converter is designed from the ground up as an offline-first, privacy-respecting application.

We do not sell, rent, or share your personal data with any third party. Your files are processed entirely on your device — they are never uploaded to our servers.

📁
Files & Documents ▼

All file operations (PDF merge, split, image conversion, compression, encryption) happen locally on your device using on-device processing only.

  • We never upload your files to any server.
  • Temporary copies created during processing are deleted immediately after the operation completes.
  • The Ghost Vault encrypts files with AES-256 and stores them only in your device's private sandbox — inaccessible to other apps.
☁️
Cloud History Sync (Optional) ▼

If you create an account and sign in, we use Firebase Firestore to store a lightweight conversion log containing:

  • The name of the output file (e.g. merged_output.pdf)
  • The tool used (e.g. "Merge PDF")
  • A timestamp of the conversion

We explicitly do NOT store the actual file content, file paths on your device, or any sensitive file metadata in the cloud.

👤
Account Information ▼

If you create an account, we collect:

  • Your email address (used for sign-in and password reset only)
  • Your chosen display name

If you use the app without signing in (Guest Mode), we create an anonymous Firebase session on your device. No personally identifiable information is associated with this session.

📱
Device Permissions ▼

We request only the permissions strictly necessary to deliver features:

  • Camera — Used by the Document Scanner to photograph documents.
  • Photo Library / Media — Used to import images for PDF conversion.
  • Storage (Android) — Used to save output files to your Downloads folder.

We never access any file outside of what you explicitly select.

📢
Advertising (Google AdMob) ▼

We display banner ads powered by Google AdMob on the Home screen to support free access to the app.

These ads may use your general device information (device model, OS version, and approximate location) to serve relevant advertisements. This is governed by Google's own Privacy Policy.

We request non-personalised ads by default to minimise data collection.

📊
Analytics & Crash Reports ▼

We currently do NOT collect any analytics, user behavioural data, or crash reports beyond what Firebase Authentication anonymously tracks for account management.

In a future version, we may introduce optional crash reporting (e.g., Firebase Crashlytics) to improve stability. This will always be clearly disclosed.

🔐
Data Security ▼
  • Firebase credentials are stored in environment variables — never hardcoded in the app binary.
  • All Firestore data is scoped to the authenticated user — no user can access another user's history.
  • Vault PINs are stored as SHA-256 hashes — the raw PIN is never persisted on disk.
  • Firebase connections use TLS encryption in transit.

If you believe a child has provided us with personal information, please contact us immediately at nicsicon.technologies@gmail.com and we will delete it promptly.
